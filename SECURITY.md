# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | ✅        |

## Reporting a Vulnerability

If you find a security issue in `promptshield` itself (e.g., a regex bypass, ReDoS, path traversal in the CLI):

1. **Do not open a public issue.**
2. Email **sandeep.mothukuris@gmail.com** with subject: `[promptshield] Security Report`
3. Include: description, reproduction steps, and impact.

I aim to respond within **48 hours** and release a patch within **7 days** for confirmed issues.

## False Negative / Bypass Reports

Found a prompt-injection or jailbreak pattern that evades detection? These are very welcome — please open a regular issue or PR with the bypass string and I'll add coverage.
